· How an agent buys here

Three steps, no shared secret.

An agent reads the profile, prices a basket, and presents a payment credential. A human only appears when the shop asks for one, which here means the age gate.

01

Read the profile

GET /.well-known/ucp lists capabilities, versions and payment handlers. No account, no key exchange.

02

Price the basket

POST /api/checkout returns line items, VAT and a session id. Restricted lines come back gated until age is asserted.

03

Present payment

Card via the platform, or an x402 stablecoin credential from /api/agent/quote. The shop never sees a PAN.

· For agents

Everything on this page has a URL.

The shelf is the same data the browser renders. Point a scraper or an agent runtime at these four endpoints and you have the whole shop.

  • GET /.well-known/ucpBusiness profile: version, capabilities, payment handlers. Cached, no redirects.
  • GET /catalog.jsonSeven products with price in minor units, stock, and restriction codes.
  • POST /api/checkoutSession pricing. Returns 422 age_verification_required for gated lines.
  • GET /api/agent/quote402 Payment Required with an x402 v2 accepts[] array. Wire shape only, no facilitator.
